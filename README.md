## 🛠️ Getting Started

Ready to dive into the cosmos? Let's get everything set up! 🚀

### 1. 📦 Install Dependencies

First things first, make sure you have [Node.js](https://nodejs.org/) installed. Then, pop open your terminal in the project directory and run:

```bash
npm install
```

### 2. 🔑 Set Up Environment Variables (Optional but recommended!)

If you want to use the magical Psychological Oracle powered by Gemini AI, you'll need an API key!

1.  Copy the example env file:
    ```bash
    cp .env.example .env
    ```
2.  Open the `.env` file and paste in your Gemini API Key:
    ```env
    GEMINI_API_KEY=your_actual_key_here
    ```

### 3. ✨ Run the Development Server

Time to launch! Start up the local development server with:

```bash
npm run dev
```

Your portal will open up at `http://localhost:3000`. So cute! 🥰

## 🏗️ Building for Production

When you are ready to share your portal with the universe, you can build it for production! 🌌

```bash
npm run build
```

This will create a `dist` folder with all your optimized static files, ready to be hosted anywhere! 📦
